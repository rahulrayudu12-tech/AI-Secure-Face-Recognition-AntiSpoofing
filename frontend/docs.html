Zero-Trust Decision Fusion Formula

To prevent presentation attacks while maintaining sub-second latency, AuraID fuses multi-spectral liveness before evaluating identity similarity: 

# Multi-Model Liveness Score
Liveness_Score = 0.45 * MultiFTNet_Fourier + 0.35 * MiniFASNet_Color + 0.20 * Temporal_LSTM

# Access Decision Rule
IF Identity_Similarity >= 0.65 AND Liveness_Score >= 0.70:
    RETURN ACCESS_GRANTED
ELSE IF Liveness_Score < 0.70:
    RETURN SPOOF_DETECTED (Attack_Type: Screen | Photo | Mask | Replay)
ELSE:
    RETURN ACCESS_DENIED (Reason: Low Identity Confidence or Unknown User)

REST API Endpoints

POST /api/authenticate

Primary real-time authentication pipeline. Receives a webcam JPEG frame in base64, runs face detection, alignment, ArcFace feature extraction, 2D Fourier MultiFTNet, chromatic MiniFASNet, and temporal LSTM motion analysis. 

// Request Body
{
  "image": "data:image/jpeg;base64,...",
  "user_id": null, // Optional: specific user ID for 1:1 match, or null for 1:N gallery search
  "simulate_attack": null // Optional: "printed_photo" | "mobile_screen" | "3d_mask" | "replay_video"
}

// Response (200 OK)
{
  "status": "success",
  "decision": "ACCESS_GRANTED",
  "granted": true,
  "user": { "id": 1, "name": "Sarah Connor", "email": "demo@auraid.cyber" },
  "identity_score": 0.9842,
  "liveness_score": 0.9450,
  "scores_breakdown": {
    "arcface_identity": 0.9842,
    "multiftnet_fourier": 0.9620,
    "minifasnet_color": 0.9380,
    "lstm_temporal": 0.8800
  },
  "attack_type": "none",
  "latency_ms": 14.2
}
POST /api/enroll-face

Enrolls a new face template. Assesses sharpness & illumination, aligns landmarks, computes 512-D ArcFace embedding, and stores into the gallery database. 

// Request Body
{
  "user_id": 1,
  "image": "data:image/jpeg;base64,...",
  "angle": "frontal"
}
POST /api/register

Creates a new user profile with bcrypt password hashing and issues a signed JWT token.

GET /api/dashboard/stats

Returns high-level cybersecurity SOC metrics: total users, enrolled faces, authentication attempts, intercepted spoof attacks, APCER, BPCER, ACER, and EER.

GET /api/logs

Retrieves recent authentication audit logs with optional filtering by decision (e.g. ?decision=SPOOF_DETECTED).
